# HTML Interview Questions and Answers

## 1. What does HTML stand for?
**Answer:** HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages.

## 2. What are the main components of an HTML document?
**Answer:** The main components of an HTML document are the `<!DOCTYPE>` declaration, `<html>`, `<head>`, and `<body>` elements.

## 3. What is the purpose of the `<head>` tag?
**Answer:** The `<head>` tag contains meta-information about the HTML document, such as the title, character set, styles, and scripts.

## 4. How do you create a hyperlink in HTML?
**Answer:** You can create a hyperlink using the `<a>` tag. For example:
```html
<a href="https://www.example.com">Visit Example</a>
```

## 5. What is the difference between `<div>` and `<span>`?
**Answer:** `<div>` is a block-level element used for grouping larger sections of content, while `<span>` is an inline element used for styling small portions of text.

## 6. What are semantic HTML elements?
**Answer:** Semantic HTML elements clearly describe their meaning in a human- and machine-readable way. Examples include `<header>`, `<footer>`, `<article>`, and `<section>`.

## 7. How do you add comments in HTML?
**Answer:** Comments in HTML are added using the following syntax:
```html
<!-- This is a comment -->
```

## 8. What is the purpose of the `<meta>` tag?
**Answer:** The `<meta>` tag provides metadata about the HTML document, such as character set, author, and viewport settings.

## 9. How can you include CSS in an HTML document?
**Answer:** CSS can be included in an HTML document using the `<link>` tag for external stylesheets, the `<style>` tag for internal styles, or inline styles using the `style` attribute.

## 10. What is the difference between HTML and XHTML?
**Answer:** XHTML is a stricter and cleaner version of HTML that follows XML syntax rules. All elements must be properly nested and closed in XHTML.

## 11. What are data attributes in HTML?
**Answer:** Data attributes are custom attributes that start with `data-` and can be used to store extra information on standard HTML elements. For example:
```html
<div data-user-id="12345">User</div>
```

## 12. How do you create a form in HTML?
**Answer:** A form can be created using the `<form>` tag, which can contain various input elements like `<input>`, `<textarea>`, `<select>`, etc. For example:
```html
<form action="/submit" method="post">
    <input type="text" name="username" />
    <input type="submit" value="Submit" />
</form>
```

## 13. What is the purpose of the `<title>` tag?
**Answer:** The `<title>` tag defines the title of the HTML document, which is displayed in the browser's title bar or tab.

## 14. How do you embed a video in HTML?
**Answer:** You can embed a video using the `<video>` tag. For example:
```html
<video width="320" height="240" controls>
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>
```

## 15. What is the purpose of the `<script>` tag?
**Answer:** The `<script>` tag is used to embed or reference JavaScript code in an HTML document. It can be placed in the `<head>` or `<body>` sections.
